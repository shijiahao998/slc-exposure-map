# Salt Lake County Facility Map

An interactive WebGIS for exploring sensitive, critical, transit, and emergency-response facilities across Salt Lake County, Utah.

Users can click any location on the map and select a **0.25, 0.5, 1, or 2 mile** radius to identify, highlight, and count nearby mapped facilities.

The map includes:

- Static basemap and optional aerial imagery
- Parcel land-use visualization
- Building footprints and 3D buildings
- Static transit routes and stops/stations
- Sensitive and critical facilities
- Fire, EMS, and other emergency-response resources
- Interactive radius-based facility analysis

The project is only intended for visualization, spatial exploration, and public-safety exposure context.
